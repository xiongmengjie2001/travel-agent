## 2. 可复跑的核对命令

骨架阶段的实质承诺是「签名先定、逻辑后补」，其可验证的残留就是**签名与 SDD 一致**：

```bash

for f in docs/module-sdd/*.md; do echo "## $f"; awk '/^## 2\./,/^## 3\./' "$f" | grep "def "; done

# 2) 代码的签名清单
for f in src/tools.py src/memory.py src/reasoning.py src/bridge.py src/scheduler.py; do
  echo "## $f"; grep "^\s*def " "$f"
done

# 3) 行为仍与 SDD 一致
pytest tests/ -v
```
